# Brilloplast - Catálogo Digital

Catálogo web para empresa dedicada a la fabricación
y venta de bolsas de polipropileno.

## Funcionalidades

- Catálogo dinámico de productos
- Filtros por medidas y características
- Vista detalle de producto
- Lista de cotización
- Envío de pedido por WhatsApp
- Formulario personalizado
- Diseño responsive

## Tecnologías

- React
- Vite
- Tailwind CSS
- JavaScript

## Arquitectura

src/
 ├── components
 ├── data
 ├── utils
 └── assets

public/
 └── productos

# Ruta de aprendizaje aplicada al proyecto

## Etapa 1 — Ejecutar y reconocer el proyecto

Objetivo: levantar la aplicación y ubicar cada archivo.

Debes poder explicar:

- Qué hace `main.jsx`.
- Qué hace `App.jsx`.
- Por qué `productos.json` es un arreglo.
- Qué representa cada componente.

## Etapa 2 — Productos desde JSON

Objetivo: comprender `.map()` y `props`.

Práctica:

1. Agrega un producto.
2. Cambia una medida.
3. Crea una tarjeta sin imagen y observa qué ocurre.

## Etapa 3 — Estado y filtros

Objetivo: comprender `useState` y `useMemo`.

Práctica:

1. Filtra por grosor.
2. Busca `20x30`.
3. Añade un nuevo color al filtro.

## Etapa 4 — WhatsApp

Objetivo: entender plantillas de texto, `encodeURIComponent` y variables de entorno.

Práctica:

1. Configura tu número temporalmente.
2. Cambia el texto del mensaje.
3. Añade el color del producto al mensaje.

## Etapa 5 — Datos reales

Objetivo: reemplazar los ejemplos por 15 productos reales antes de cargar 200.

## Etapa 6 — Automatización con Excel

Objetivo: generar `productos.json` a partir de una hoja ordenada.

## Etapa 7 — Publicación

Objetivo: subir el repositorio a GitHub y desplegarlo en Cloudflare Pages.
